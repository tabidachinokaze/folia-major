# 队列界面验证模组

把本目录复制到开发版或用户模组目录，以“队列界面（样例）”启用。它是未签名的开发用模组，需要 Folium 1.5；不请求网络、存储或播放权限，也不会发送任何账号消息。

宿主的队列标签页、队列命令（Ctrl/Cmd+P）和 Lattice 都会显示同一首歌曲的两个独立条目，推荐者分别为 Alice 与系统推荐。点击房间点赞按钮可连续更新当前条目的计数。标题同步按钮只记录动作日志。

播放器面板的“队列示例”标签页提供增、删、重排、改插槽、恢复宿主和显示示例按钮。开启“改插槽”后，可以在队列标题、条目动作、命令工具栏与真实 Lattice 工具菜单观察新增动作；原生筛选提示会被改写。操作日志显示在该标签页，并发送到 `folium.log.info`。

依次检查增加、删除、重排同媒体的条目，连续点赞，以及开启/关闭列表修改；关闭模组后确认原队列、控件、当前歌曲与播放状态恢复。UI 显示源没有音频控制权，点击条目不启动音频，拼贴卡片进度禁用，也不会显示私人歌曲的歌词。这些限制是本示例演示的接口边界。
