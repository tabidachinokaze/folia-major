# Folia {{VERSION}} · 一起听图标与聊天布局

**推荐配套：Folia 0.7.15 + Music Party 插件 0.3.10。** 请升级 Folia，并安装、重新启用新版插件。

- 一起听侧栏与播放栏统一使用两侧带声波的双人图标。模组可提供自定义线条图形，继续跟随宿主主题颜色。
- 配套插件修复长歌名导致匹配卡片溢出，精简房间聊天工具栏；输入框提示如何使用 @，发送按钮保持在同一行。
- 配套插件将私信歌曲、专辑分享整合为带封面、类型、标题和歌手的音乐卡片，并补全点赞动态的昵称去重。
- 成员待播歌曲的置顶次数显示在置顶按钮内，与原生队列操作一致。

[下载 Music Party 0.3.10](https://github.com/tabidachinokaze/folium-mod-music-party/releases/tag/v0.3.10)。

## 下载

- Windows：`.exe` 安装包。
- macOS：按 CPU 架构选择 `.dmg`；首次打开未签名应用的说明见 [macOS 安装说明](https://github.com/tabidachinokaze/folia-major/blob/main/docs/desktop/macos-app-damaged.md)。
- Linux：按发行版选择 `.deb`、`.rpm` 或 `.tar.gz`。
- `SHA256SUMS` 提供安装包校验值。`.yml`、`.blockmap` 和 macOS `.zip` 同时供应用更新器使用。

首次从上游迁移需安装本 fork 的安装包。后续更新从本仓库 Releases 获取；插件 ZIP 单独更新。
