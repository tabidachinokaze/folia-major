# Folia {{VERSION}} · 私信资源卡片与专辑导航

**推荐配套：Folia 0.7.17 + Music Party 插件 0.3.11。** 更新宿主后安装并重新启用新版插件。

- 私信专辑卡片打开原生专辑页，返回后继续查看会话，保持播放状态不变。
- 配套插件将活动、会员通知、歌手推广的正文、封面和资源信息合并成一张卡片，补全音乐预览。
- 配套插件支持点击歌曲播放或推荐到一起听待播队列，活动卡片打开对应链接；只有原生入口的官方活动通过网易云应用打开。
- 预约卡片保留预约入口，不把预约 ID 当成已上架歌曲。

[下载 Music Party 0.3.11](https://github.com/tabidachinokaze/folium-mod-music-party/releases/tag/v0.3.11)。

## 下载

- Windows：`.exe` 安装包。
- macOS：按 CPU 架构选择 `.dmg`；首次打开未签名应用的说明见 [macOS 安装说明](https://github.com/tabidachinokaze/folia-major/blob/main/docs/desktop/macos-app-damaged.md)。
- Linux：按发行版选择 `.deb`、`.rpm` 或 `.tar.gz`。
- `SHA256SUMS` 提供安装包校验值。`.yml`、`.blockmap` 和 macOS `.zip` 同时供应用更新器使用。

首次从上游迁移需安装本 fork 的安装包。后续更新从本仓库 Releases 获取；插件 ZIP 单独更新。
