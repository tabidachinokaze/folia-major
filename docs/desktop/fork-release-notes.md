# Folia {{VERSION}} · 一起听页签图标

**推荐配套：Folia 0.7.14 + Music Party 插件 0.3.9。** 请升级 Folia，并安装、重新启用新版插件。

- 模组可以使用自己的侧栏页签图标。一起听入口改为双人图标，与播放栏入口一致；未配置图标的模组继续使用原有默认图标。
- 配套插件的选歌、Emoji、颜文字、表情包与图片弹窗优先显示在侧栏左侧，减少遮挡。
- 配套插件增加聊天头像，修复横向溢出及 UP 动态重复昵称；成员页显示当前歌曲推荐者，并调整已播归类与置顶状态。

[下载 Music Party 0.3.9](https://github.com/tabidachinokaze/folium-mod-music-party/releases/tag/v0.3.9)。

## 下载

- Windows：`.exe` 安装包。
- macOS：按 CPU 架构选择 `.dmg`；首次打开未签名应用的说明见 [macOS 安装说明](https://github.com/tabidachinokaze/folia-major/blob/main/docs/desktop/macos-app-damaged.md)。
- Linux：按发行版选择 `.deb`、`.rpm` 或 `.tar.gz`。
- `SHA256SUMS` 提供安装包校验值。`.yml`、`.blockmap` 和 macOS `.zip` 同时供应用更新器使用。

首次从上游迁移需安装本 fork 的安装包。后续更新从本仓库 Releases 获取；插件 ZIP 单独更新。
