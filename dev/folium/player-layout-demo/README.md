# 播放器布局避让示例

将本目录复制到开发版 `mods/player-layout-demo` 或已安装 Folia 的用户模组目录，重新扫描并启用后，播放页显示左下示例聊天和右上示例对话。此开发示例没有官方签名，需要手动确认。无账号、网络请求或发送动作；布局只读取 `ctx.getLayout()`，不查询宿主 DOM。

人工检查：

1. 播放页移动鼠标到左上角，确认返回按钮仍可唤出并点击。
2. 显示和隐藏底栏，调整底栏高度；示例内容应跟随避让。
3. 打开、关闭右侧面板，确认右上示例框避开面板。
4. 显示正在播放卡片及状态 Toast，缩小、最大化窗口，确认内容仍在窗口内。
5. 切回首页，示例内容应消失；关闭模组后应完全移除。

只有示例框与原生控件矩形真正相交时才移动。下部面板不应挤走上方的私信框；聊天为返回按钮实际点击区域留白，较大的鼠标唤出范围仍能跨过示例内容工作。

Web 探针：`npm run dev:probe` 后打开 `?probe=playerLayout`，可在无账号条件下检查返回按钮、卡片、底栏、Toast 与侧栏几何。自动组件测试不代替提交者的真实桌面人工验证。
